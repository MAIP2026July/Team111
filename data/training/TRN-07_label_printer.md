## Module overview
Quick start for label printer LP-4.

## Steps
1. Select the product code and confirm it matches the work order.
2. Load labels gloss side out and ribbon ink side facing the label.
3. Run Auto-calibrate from the Media menu.
4. Print and scan a test label; grade C or better.
