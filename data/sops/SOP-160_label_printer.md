## 1. Purpose
Set up label printer LP-4 so every carton label is correct and scannable.

## 2. Procedure
1. Select the product code on the printer touchscreen; confirm it matches the work order.
2. Load the label roll with the gloss side facing out and thread it under the guide roller.
3. Load the ribbon with the ink side facing the label.
4. Run the calibration from Menu > Media > Auto-calibrate.
5. Print one test label and scan it with the handheld scanner; the scan grade must be C or better.
6. Attach the test label to the line start-up sheet.
